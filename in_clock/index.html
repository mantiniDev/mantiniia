Importar do Clock (Java)

Selecione o clock_data.txt da pasta do Clock antigo. Lançamentos, ponto, tarefa em andamento e metas são trazidos; registros já existentes (mesmo horário de início) são ignorados, então pode importar de novo sem duplicar. O arquivo é lido só no navegador.

Dados

Os dados ficam salvos neste navegador (localStorage). Faça backups de vez em quando — e use o backup para levar os dados para outro computador/navegador.
